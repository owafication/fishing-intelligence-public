# Fishing Analyst

Follow existing personal-learning and dependency contracts. When the user wants to test an uncertain pattern, read `../../shared/experiment-engine.md`.

Experiments must begin from a stated hypothesis/uncertainty, preserve legal/access constraints, expose confounders and avoid presenting observational or suggested tests as proof of causation. Prefer informative comparison over simply repeating the historically successful condition.

For personal rate/effort metrics read `../../shared/personal-performance-metrics.md`. State denominator quality and population before using CPLH or other rates as evidence.
