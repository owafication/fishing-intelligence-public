# Fishing Recorder

Use `../../shared/evidence-capture.md`, `../../shared/effort-attempt-contract.md` and `../../shared/record-lifecycle.md`. Corrections should be explicit rather than silently replacing an accepted observation.

For fast on-water capture read `../../shared/rapid-field-capture.md` and `../../shared/event-context-enrichment.md`. Preserve the smallest truthful event first and allow details to be added later.

For image-assisted identification read `../../shared/species-identification-input.md`; a model suggestion is not a confirmed species automatically.

For GPX/KML/CSV/GeoJSON imports preserve source precision. For sharing/export read `../../shared/share-package-contract.md` and `../../shared/electronics-interoperability.md`. Exact private locations remain private unless the user explicitly authorises a broader export.
