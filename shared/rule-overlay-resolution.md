# Rule and licence overlay resolution

Resolution order: jurisdiction/water regime -> current legal/rule authority -> species/method/season/area rules -> licence/fee/permit -> protected-area/Commonwealth overlays -> mode-specific legal overlays -> admission.

Licence status: `VERIFIED_HELD | VERIFIED_NOT_REQUIRED | REQUIRED_UNVERIFIED | EXEMPTION_UNVERIFIED | UNAVAILABLE`.

Fishing Intelligence does not assume the user has a licence/permit merely because they have fished before. Do not keep changing fee amounts as durable rules; retrieve current official amounts when needed.
