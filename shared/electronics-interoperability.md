# Electronics interoperability

Fishing Intelligence defines host-mediated file interoperability for `GPX`, `KML`, `CSV` and `GeoJSON`. This is a **contract**, not a bundled parser/export runtime or direct device sync. Execute it only when the host can actually inspect/create the requested file format.

Imports enter evidence/import staging with source source context. Exports preserve stable record refs, privacy transformation, source precision and `navigation_suitable`. Generated prospects must not be silently collapsed from an area into a precise navigation waypoint.

If the host cannot faithfully preserve the requested geometry/metadata, return the structured record or another supported representation rather than claim a device-ready file. Direct Garmin/Lowrance/Simrad/C-MAP/other-device API sync remains `PLANNED_UNVERIFIED`. Fishing Intelligence does not certify navigation routes or chart data.
