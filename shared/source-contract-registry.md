# External source registry

Regional packs should identify the external source needed for each material decision.

Useful fields include:
- source ID and provider;
- authority class and jurisdiction/scope;
- source URL;
- purpose;
- checked-at/effective time when retrieved;
- freshness/recheck rule;
- failure consequence.

The package stores source links and routing metadata, not copied live pages, forecasts or tide tables. If a current source cannot be reached, do not substitute model memory for a consequential current fact.
