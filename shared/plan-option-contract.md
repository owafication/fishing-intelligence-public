# Plan option contract

Every presented option contains:
- `option_id` and objective label;
- readiness state;
- fishing mode/opportunity family;
- target intent (`SPECIFIED | FAMILY | GENERAL`);
- access/launch choice if relevant;
- bounded time sequence using only justified precision;
- prospect types and evidence class;
- advantages/trade-offs;
- material unknowns;
- invalidation/recheck conditions;
- verification summary refs;
- optional session state.

## Comparison
Prefer 1–3 materially different options. Do not generate filler alternatives that differ only cosmetically. Never present an opaque global score.

## Recheck/invalidation
Examples include forecast/warning change, ramp status change, authoritative tide resolution changing threshold admission, changed return time, fuel/range becoming insufficient, regulation change, or user objective change.
