# NT boat-ramp/access reference procedure

Source ID: `AU-NT-GOV-BOAT-RAMPS`.

1. Open the registered current ramp page and record `checked_at`.
2. Resolve the named ramp row exactly.
3. Extract only decision-relevant fields: ramp name/location, documented tidal-access estimate, current status/warning and owner/contact where needed.
4. Preserve the page's qualification that tidal-access values are estimates and can change with environmental conditions.
5. Treat thresholds as ramp/access constraints only; never convert them into general water-depth or navigation claims.
6. If current status cannot be checked within freshness policy, access verification becomes `UNAVAILABLE`/`STALE` and dependent readiness is downgraded or blocked.
7. Search for and preserve any current material access constraint associated with the candidate launch/route when the registered/current evidence exposes one (for example a closure, threshold, obstruction/bar warning or restriction). If an alternative is mapped/listed, attach that constraint to the alternative instead of presenting the location alone.
