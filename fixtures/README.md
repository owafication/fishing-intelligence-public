# Deterministic public fixtures

Included fixture groups test stable behavior only:

- `ph03` planning/admission;
- `ph04` prospect precision/closure behavior;
- `ph09` Australian jurisdiction dispatch;
- `ph09b` Adelaide planning-source boundaries;
- `ph12` global regional-source generation;
- `ph13` authority applicability/intersection.

Mutable live weather, tide and temporary regulation values are intentionally not frozen into these fixtures.
