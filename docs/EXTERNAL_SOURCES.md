# External sources

Fishing Intelligence uses external source **links** to verify current rules, access, warnings, weather, tide/water level, navigation notices and other time-sensitive facts.

The repository does not bundle current forecasts, tide predictions or copied regulatory pages. Regional registries point to source providers so the host can retrieve current information when needed.

Source links can change. When a link fails, resolve the current official source rather than relying on stale embedded facts.
