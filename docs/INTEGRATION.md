# Integrations

Fishing Intelligence is portable-only and does not require its own backend, database or synchronization service.

## Current references

When current law, closures, access, weather, tide or notices materially affect a decision, use the host's available reference/web capability to open the linked authoritative source. If current reference access is unavailable, keep the dependent conclusion unverified rather than filling it from memory.

## Files

When the host supports file input/output, Fishing Intelligence can work with GPX/KML/CSV/GeoJSON-style data as bounded user inputs or exports. Generated prospects are not certified navigation routes.

## Images

When image input is available, a fish-identification suggestion may be used as supporting input. Exact species remains unresolved when confidence is insufficient for a rule-dependent decision.
