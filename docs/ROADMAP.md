# Roadmap

Potential future work, not current claims:

1. deterministic file import/export runtime for GPX/KML/CSV/GeoJSON;
2. more regional `PLANNING_READY` and `PROSPECT_READY` packs;
3. optional companion app for map/GPS/offline field capture;
4. production-grade store adapters beyond the current Google Drive contract;
5. direct device/cloud integrations where rights and APIs allow;
6. verified media metadata scrubbing;
7. optional multi-user/shared-trip access controls;
8. service/API wrapper for third-party fishing apps.

Every item stays unimplemented until evidence supports a stronger claim.

## 0.15 delivered in DEV
- Global regional-pack resolution/generation.
- Navigation-notice and boating/safety requirement resolution.
- Species/taxon plus unit/timezone/datum safeguards.

## Candidate future work
- Personal tackle-effectiveness intelligence using attempt/effort denominators rather than generic lure popularity.
- Party/boat catch-limit state for group trips where jurisdiction rules support it.
- Biosecurity, invasive-species and harvest-health advisory depth for regions where these materially affect fishing.
- Waterbody knowledge profiles and access-point intelligence with source context/freshness.
- Change-detection workflows for previously generated regional packs when authoritative rules/notices materially change.
