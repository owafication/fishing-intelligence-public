# Limitations and non-claims

The public package intentionally does **not** claim:

- a shipped native mobile/field application;
- continuous background geofencing, rule monitoring or automatic alerts;
- a proprietary production fish-identification model;
- direct chartplotter/cloud-device synchronization;
- a bundled deterministic production GPX/KML/CSV/GeoJSON parser/exporter;
- binary/photo/EXIF metadata scrubbing;
- a shared multi-user authentication/ACL backend;
- bookings, payments or CRM;
- certified navigation, emergency response or safety certification;
- current live weather/tide/rule availability without an actual current-source capability;
- uniform local planning/prospect/source depth worldwide;
- universal or causal biological truth from one user's fishing history;
- guaranteed fishing success.

The reference scripts are executable contract examples/tests, not a production hosted backend. Regional packs contain source-routing and readiness metadata; they do not freeze mutable law/environment facts as permanently current.

- Generated regional packs depend on accessible, current authoritative sources; blocked/ambiguous authority remains unresolved rather than guessed.
- Global support does not guarantee a local ramp database, bathymetry, tide/current service or prospect dataset for every waterbody.
- Boating/safety requirement resolution does not certify vessel compliance or trip safety.

- Spatial applicability can remain `UNRESOLVED` when official geometry or sufficiently precise named-area/route evidence is unavailable; the plugin does not invent a route-clear conclusion.
- Travel time/distance/fuel burden is not inferred when current routing or user vehicle/vessel information is unavailable.
