# FAQ

## Does it predict exactly where fish will be?
No. It compares evidence, conditions and prospective structure while preserving uncertainty. Generated prospects are hypotheses/search areas.

## Does it replace a marine chart or navigation app?
No. It is not certified navigation.

## Does it know current fishing rules from memory?
It should not rely on model memory for consequential current legal/keeper guidance. It verifies authoritative current sources when web access is available.

## Does it need Google Drive?
No. Portable mode is the default. Google Drive is one optional durable-store adapter.

## Does it identify fish from photos?
Only when the host supplies image/vision capability. A model result is a proposed identification until confirmed.

## Does it learn from blanks?
Yes, when positive effort is recorded. Absence of a catch record alone is not a blank.

## Can it share my marks?
Exact locations are private by default. Sharing requires explicit transformation/authorisation and media metadata is not assumed scrubbed.
