# Capabilities

| Capability | Status | Boundary |
|---|---|---|
| Trip planning and comparison | Supported | Hard constraints before optimisation |
| Global authority resolution | Supported with current reference access | Depth varies by jurisdiction |
| On-demand regional source packs | Supported | Temporary and source-linked |
| Navigation/temporary restriction checks | Supported when applicable | Not certified navigation |
| Boating requirement checks | Supported when applicable | Does not certify vessel compliance or safety |
| Species/taxon rule binding | Supported when material | Ambiguity can withhold keeper/method advice |
| Weather/tide source resolution | Supported with current reference access | No bundled live forecast/tide dataset |
| Prospect intelligence | Supported where regional evidence is adequate | Search areas, not navigation instructions |
| Catch/blank/effort capture | Supported in the active session | No persistent-store requirement |
| Personal learning and metrics | Supported | User-specific; no causal guarantee |
| Active-trip replanning | Supported | Completed events are not rewritten by replanning |
| Image-assisted fish ID | Optional host input | Suggestion is not automatically confirmed |
| File import/export | Optional host file I/O | No direct chartplotter synchronization |
| Bookings/payments/CRM | Out of scope | — |
