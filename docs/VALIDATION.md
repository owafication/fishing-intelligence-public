# Validation

`python scripts/validate.py` performs the public release validation suite.

Coverage includes:
- manifest/version consistency and public-submission metadata constraints that can be checked offline;
- JSON parse integrity;
- sensitive/private build-system and local-identity leakage scan;
- skill-relative reference existence;
- required standalone/public documentation;
- regional readiness/source-contract structural checks;
- executable feature-fixture suites where a deterministic reference engine exists;
- retained critical boundaries: privacy by default, idempotent offline sync, non-navigational generated prospects, immutable completed history and explicit binary scrubber limitation.

Passing this suite establishes package/static behavior only. It does not prove live external-source availability, App Store/mobile runtime behavior or publication approval.

PH13 deterministically checks option-scoped authority applicability and spatial-intersection semantics.
